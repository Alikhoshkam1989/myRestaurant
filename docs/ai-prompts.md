# AI-verantwoording en gebruikte prompts

Ik heb deze opdracht zelf gemaakt. Op 15 en 16 september 2026 heb ik OpenAI Codex in de desktopapp om hulp gevraagd als ik vastliep bij de opdracht, een stuk code, een test of een formulering. De keuzes in de applicatie zijn van mij.

## Gebruikte prompts

1. `kun je uitleggen wat ik in deze opdracht zelf moet doen?`
2. `ik begrijp dit stuk niet. kun je het uitleggen, zodat ik het zelf kan schrijven?`

Ik heb geen aparte subagents gebruikt.
